# tools

This repo contains my public tools.

## Tampermonkey

The `tampermonkey` folder contains userscripts. To install one, open Tampermonkey,
create a new script, and use "Utilities" > "Import from URL" with the raw GitHub URL
of the script, e.g.:

```
https://github.com/clboettcher/tools/raw/refs/heads/main/tampermonkey/google-calendar-durations.user.js
```

Alternatively, most browsers with Tampermonkey installed will prompt to install the
script automatically when you navigate directly to its raw URL.
